# Журнал изменений

Формат — Keep a Changelog, версии — SemVer.

## 2.0.0-alpha.3 — 31.10.2026

### Добавлено

- Выпуск одной кнопкой (`release.yml`): dev → main, тег, сборка APK и EXE, страница релиза с заметками из этого журнала, обновление сайта.
- Сборка APK (Capacitor 6): `platforms/android/build.sh`, приложение ставится рядом с 6.x (`ru.skat.skat2`).
- Сборка EXE для Windows (Electron, portable): `platforms/windows/`, протокол `app://`, один экземпляр приложения.

### Изменено

- Офлайн-кэш (service worker) включается только в браузере: в EXE файлы и так локальные.

## 2.0.0-alpha.2 — 31.10.2026

### Добавлено

- Хранилище на устройстве (IndexedDB `skat2`) с проверкой данных при загрузке: испорченные настройки не роняют приложение.
- Резервная копия всех данных, кроме тайлов, в файл и восстановление из него.
- Темы «Ночное видение» и «Красная ночная», переключатель в настройках; тема применяется ещё на заставке.
- Шрифты Golos Text и IBM Plex Sans Condensed встроены в сборку.
- Заставка при запуске.
- PIN-код на вход (CORE-15, первая часть): ключ данных AES-256-GCM закрыт ключом из PIN, PBKDF2 210 000 итераций; пауза 30 с после каждых 5 ошибок; сброс данных при забытом PIN. Шифрование самих данных подключится вместе с проектами.
- Работа без сети: service worker кэширует все файлы сборки; стабильная версия и бета не мешают друг другу.
- Экран настроек: тема, PIN, резервная копия, состояние хранилища.

## 2.0.0-alpha.1 — 31.10.2026

### Изменено

## 2.0.0-alpha.0 — 31.10.2026

### Добавлено

- Каркас проекта: TypeScript strict, Vite 8, Preact + signals.
- `npm run check`: типы, ESLint, Prettier, границы модулей (dependency-cruiser), тесты Vitest с покрытием ядра не ниже 90 %.
- Пересчёт СК-42 перенесён из 6.x, тесты по эталонным точкам.
- Экран выбора режима и пустые оболочки четырёх режимов: каждая — отдельный ленивый чанк, ошибка режима не роняет приложение.
- Доставка архивом: `apply-patch` → `dev` → бета на Pages.

### Перенесено

- `ARCHITECTURE.md` и `FEATURES.md` — в `docs/`.

### Удалено
